# Reseräknare – webben

Körjournalen i webbläsaren (iPhone, dator). Resorna kommer från skärmen i bilen via Supabase.
Logga in med e-post (länk i mejlet). Vad man ser styrs av rollen i databasen: förare sina egna resor,
konsult allt i företaget, kontor bara summor per kund.

Sidan innehåller bara Supabase-projektets publika nyckel – ingen data och inga hemligheter.
